# 사주 작명 노트

사주팔자를 세우고, 대법원 인명용 한자로 이름을 검토하는 정적 웹사이트입니다. 서버가 필요 없어서 `index.html`을 브라우저로 열면 바로 동작합니다.

## 파일

```
site/
  index.html        화면 구조
  styles.css        디자인 토큰과 레이아웃 (주간/야간)
  app.js            사주 계산, 여섯 가지 검사, 후보 탐색, 순위 차트
  data/
    hanja.js        인명용 한자 9,729자 (window.HANJA_DATA)
    popularity.js   2015~2026년 이름 순위 TOP 100 (window.POP_DATA)
    suri-text.js    81수리 해설 (window.SURI_TEXT)
```

다섯 파일 모두 있어야 동작합니다. 다른 곳으로 옮길 때는 `site` 폴더를 통째로 복사하세요.

데이터를 `.js`로 감싼 이유는 `file://`로 열었을 때 `fetch`가 막히기 때문입니다. 스크립트 태그로 불러오면 로컬에서도 동작합니다.

## 계산 방식

| 항목 | 방식 |
|---|---|
| 년주 | 입춘(2월 4일 근삿값) 기준으로 해를 바꿔 60갑자 계산 |
| 월주 | 24절기 절입일 근삿값으로 월지를 정하고, 년간에서 월간을 유도 |
| 일주 | 율리우스 적일(JDN) 기준 60갑자 |
| 시주 | 태어난 지역의 경도로 시각을 보정한 뒤 시지를 정하고, 일간에서 시간을 유도. 자시(23시 이후)는 다음 날 일주로 넘김 |
| 경도 보정 | 한국 표준시는 동경 135도 기준이라 실제 태양시보다 빠릅니다. `(경도 − 135) × 4분`으로 보정합니다. 서울 −32분, 부산 −24분 |
| 획수 | 강희자전 부수 원획법. Unihan `kRSUnicode`의 부수 번호와 잔획을 더해 계산 |
| 자원오행 | 부수 214개를 오행으로 분류한 표 기준 (참고값) |
| 사격 | 원격=이름 두 글자, 형격=성+첫 글자, 이격=성+끝 글자, 정격=전체. 외자는 가성수 1 적용 |
| 수리오행 | 각 격의 끝자리를 오행으로 변환 (1·2 목, 3·4 화, 5·6 토, 7·8 금, 9·0 수) |
| 대운 | 년간 음양과 성별로 순역을 정하고, 다음 절입일까지의 날수를 3으로 나눠 시작 나이 산출 |

## 데이터 출처

- 인명용 한자 목록: [rutopio/Korean-Name-Hanja-Charset](https://github.com/rutopio/Korean-Name-Hanja-Charset) (대법원 전자가족관계등록시스템 수집본)
- 획수와 부수: [Unicode Unihan Database](https://www.unicode.org/Public/UCD/latest/ucd/)
- 이름 순위: [아기이름(baby-name.kr)](https://baby-name.kr/) 연도별 순위 (대법원 출생신고 집계 정리)

## 갱신 방법

이름 순위는 해마다 새로 수집해야 합니다. `data/popularity.js`의 `window.POP_DATA` 값을 새 데이터로 바꾸면 됩니다. 형식은 `{ "2026": { "male": [[순위, 이름, 인원], ...], "female": [...] } }` 입니다.

## 한계

- 월주는 절기 날짜만 보고 시각은 보지 않습니다. 절기 당일 출생은 한 칸 어긋날 수 있습니다.
- 자원오행은 부수 기반 자동 분류라 작명가마다 다르게 볼 수 있습니다. 화면에 부수를 함께 띄우니 대조해서 쓰세요.
- 81수리와 발음오행 해석은 전통적인 참고 기준이며 검증된 과학적 근거는 없습니다.
- 출생신고 전에 대법원 인명용 한자 조회로 사용 가능 여부를 반드시 확인해야 합니다.
